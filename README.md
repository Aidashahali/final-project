# Smart Document Classification System

This project implements an intelligent system for automatic classification of identity documents (e.g., National ID cards, driver's licenses) using Deep Learning techniques. The goal is to provide an accurate, efficient, and cloud-independent solution for internal document processing.

## Key Objectives

*   **Automatic Document Classification:** Accurately identify various types of identity documents.
*   **Handling Imbalanced Data:** Perform well even with a low number of samples in certain classes.
*   **CNN Baseline Model:** Implement an initial Convolutional Neural Network (CNN) based model.
*   **Model Improvement:** Utilize techniques like Regularization, Dropout, and Augmentation.
*   **Performance in Adverse Conditions:** Function reliably with low-quality images, poor lighting, or unusual angles.
*   **No GPU Requirement:** Enable training and deployment on standard hardware.

## Challenges

*   Accurate classification of different document types.
*   Robust performance in real-world, suboptimal conditions.
*   Managing significant data imbalance across classes.

## Technologies

*   Deep Learning
*   Convolutional Neural Networks (CNN)
*   (Deep learning framework, e.g., TensorFlow or PyTorch)
# سیستم هوشمند طبقه‌بندی خودکار اسناد

این پروژه یک سیستم هوشمند برای طبقه‌بندی خودکار اسناد هویتی (کارت ملی، گواهینامه و غیره) با استفاده از یادگیری عمیق (Deep Learning) است. هدف، ایجاد راهکاری مستقل و دقیق برای پردازش اسناد داخلی است.

## اهداف کلیدی

*   **طبقه‌بندی خودکار اسناد:** تشخیص دقیق انواع اسناد.
*   **مدیریت داده‌های نامتوازن:** عملکرد خوب حتی با داده‌های کم در برخی کلاس‌ها.
*   **مدل پایه CNN:** پیاده‌سازی مدل اولیه مبتنی بر شبکه‌های عصبی کانولوشنی.
*   **بهبود مدل:** استفاده از تکنیک‌های Regularization، Dropout و Augmentation.
*   **عملکرد در شرایط نامطلوب:** مقاومت در برابر کیفیت پایین تصویر، نور ضعیف و زوایای نامناسب.
*   **عدم نیاز به GPU:** قابلیت آموزش و اجرا روی سخت‌افزارهای معمولی.

## چالش‌ها

*   تشخیص دقیق انواع اسناد.
*   عملکرد مطلوب در شرایط واقعی و نامطلوب.
*   مدیریت عدم تعادل شدید در داده‌ها.

## تکنولوژی‌ها

*   یادگیری عمیق (Deep Learning)
*   شبکه‌های عصبی کانولوشنی (CNN)
*   (چارچوب یادگیری عمیق مانند TensorFlow یا PyTorch)
